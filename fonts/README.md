# Fuentes

| Archivo | Uso |
|---|---|
| `Sloop-ScriptThree.ttf` | Letra manuscrita: nombres, "Los", la frase, el sello |
| `Brown-Sugar-Regular.ttf` | Títulos en mayúsculas: "DETALLES", "LUGAR Y HORA", la fecha |

El texto normal usa **Lora** de Google Fonts. Para cambiarla, añade el archivo aquí, crea una regla
`@font-face` en `css/styles.css` y ponla al principio de `--text`.

Antes de publicar, comprueba que la licencia de cada fuente permite usarla en una web.
